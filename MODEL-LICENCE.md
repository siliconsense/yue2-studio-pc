# Model licence

This repository contains **no model weights**. On first run the installer
downloads them from the authors' own Hugging Face repositories:

| File | Source | Licence |
|---|---|---|
| `yue2_3b_int8_convrot.safetensors` | [Comfy-Org/YuE2](https://huggingface.co/Comfy-Org/YuE2) | CC BY-NC 4.0 |
| `sheetsage2_bf16.safetensors` | [Comfy-Org/YuE2](https://huggingface.co/Comfy-Org/YuE2) | CC BY-NC 4.0 |

Both are quantised builds of [m-a-p/YuE2-3B](https://huggingface.co/m-a-p/YuE2-3B)
and [m-a-p/SheetSage2](https://huggingface.co/m-a-p/SheetSage2) by
**Multimodal Art Projection** and **HKGAI**.

**CC BY-NC 4.0 means non-commercial use.** Personal use is free, and the model's
authors state that no fees or royalties are owed to them for the tracks you make.
Commercial use by a company is arranged with the authors separately — see the
model card for contacts.

The engine is [ComfyUI](https://github.com/comfyanonymous/ComfyUI), cloned at
install time from its own repository under its own licence.
